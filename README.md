# 🌟 Admin Dashboard  

A modern, responsive **Admin Dashboard** built with **Next.js**, **React**, **Tailwind CSS**, and **Framer Motion** — designed for clean analytics visualization, smooth animations, and intuitive user control.  

### 🚀 Features  
- 📊 **Sales Overview & Analytics:** Interactive charts and data insights.  
- 🧾 **Category Distribution:** Visualized product categories with dynamic updates.  
- ⚙️ **Settings Page:** Manage profile info, passwords, and notifications easily.  
- 💬 **Help & Support Center:** Built-in FAQs and contact form with instant feedback.  
- 🌙 **Dark Mode Interface:** Minimal and professional dark UI for better focus.  
- 🔄 **Responsive Layout:** Optimized for all screen sizes — desktop, tablet, and mobile.  

### 🧩 Tech Stack  
- **Next.js 14** (App Router)  
- **React 18**  
- **Tailwind CSS** for modern, responsive styling  
- **Framer Motion** for smooth UI transitions  
- **Lucide Icons** for consistent iconography
